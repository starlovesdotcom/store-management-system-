# Store Management System

A command-line inventory system built in Python for managing a store's product catalog.

## Table of Contents
- [Features](#features)
- [Requirements](#requirements)
- [How to Run](#how-to-run)
- [Example](#example)

## Features
- Add products
- View all products
- Update price/stock
- Sell a product
- Low-stock alerts
- Exit

## Requirements
- Python 3

## How to Run
```bash
python store_manager.py
```

## Example
```
Enter your choice:('1-6') 4
Enter the name of your product: milk
Enter the quantity you want to sell: 5
Product sold successfully!
Remaining stock of Milk : 15
```
